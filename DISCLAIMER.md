This is an unofficial patch workflow for a legacy Parrot Android app.

FLIR, Google, Samsung, or any other third party.

The repository intentionally does not distribute:

- FreeFlight Thermal APKs or XAPKs
- OBB expansion files
- Parrot/FLIR firmware
- native libraries from the original application
- decompiled application source code
- proprietary assets

Users must provide their own copy of the original FreeFlight Thermal 3.0.4
package. The scripts verify known SHA-256 values before patching.

Do not update drone, Skycontroller 2, or FLIR ONE Pro firmware as part of this
process. The tested fix was done without firmware updates, factory resets,
flashing, or bootloader changes.
